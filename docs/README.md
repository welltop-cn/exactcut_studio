## 历史资料

[归档入口](archive/README.md)集中保存旧架构、实施计划、审查、交接和一次性验收证据。归档表示它们不再是日常操作入口，**不表示所有计划都已实施或所有问题都已解决**。仍需处理的事项已收拢到[项目状态](status.md)。

## 后续维护

- 行为变化时更新对应主文档；避免在多个入口追加同一份“当前状态”。
- 新的一次性验收记录放入 `docs/archive/verification/`；生产操作同时更新线上变更索引，未完成事项同时更新项目状态。
- 过期计划和交接放入归档，保留日期、固定版本、失败及验证范围；调整路径时一并修正引用。
- 主文档不保存临时 PID、私人路径、凭据或签名 URL。实例是否运行、线上究竟加载哪个版本，应在操作前核对。
