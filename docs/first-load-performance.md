# 首屏加载优化（2026-10-10）

## 实测与原因

域名 `https://autocut.creativefitting.ai/home/` 的一次已登录浏览器刷新记录：FCP 1.26 秒，DOMContentLoaded 3.29 秒；app.js 71,366 字节，传输 2.06 秒。用户信息、工作区、项目列表依次完成，空列表直到 5.31 秒返回，随后立即重复请求列表。该记录不能代表所有网络环境，也不能作为优化后的延迟承诺。

## 修改

- 并行请求用户身份和工作区初始化；两者完成后才加载项目列表。工作区可能创建默认项目，不能与列表随意并行。
- 恢复项目时复用刚获取的列表，重绘选中项；普通项目切换仍刷新列表。
- 初始化期间禁止轮询重入，取消初始化后的立即重复轮询；原 3 秒状态轮询及源片预取保留。
- 三个静态脚本采用 SHA-256 内容版本 URL。仅版本匹配时使用 private immutable 缓存；HTML、API、错误响应保持 no-store。部署或回滚改变文件内容后，HTML 自动引用对应新版本。
- 按 Accept-Encoding 协商压缩静态脚本，返回 Vary；gzip;q=0 不压缩。动态账户/业务数据不参与压缩，脚本请求仍经过认证。

主脚本本次从 71,625 字节压缩到 23,484 字节（约减少 67%）。未进行线上发布；实际首屏改善需要部署后在同一浏览器和网络条件复测。

## 验证

新增真实 HTTP 验证压缩往返、缓存范围、未认证访问、过期版本和禁用 gzip；Node 执行真实初始化代码，验证并行身份/工作区请求、依赖顺序、单次列表、链接恢复及轮询锁释放。已有工作区测试覆盖默认项目、用户隔离、记忆选择和无效链接回退。完整回归在不含开发数据的隔离副本运行。
