# 项目切换后串素材：修复与验证（2026-10-13）

> 历史归档（2026-11-04）。正文保留当时的方案或执行状态，不代表当前版本；日常操作见[文档入口](../../README.md)。

## 根因复现

基线2217055，线上反馈版本的同一前端路径。在无生产数据、无外部服务调用的Chromium中，使用实际index.html/app.js及符合后端代码契约的合成项目：

1. 项目A已经渲染素材RA。
2. 缓存项目B为queued，附带download_prefetch和当前下载集；下载计划位于顶层plan。
3. openBatch切到B：displayBatch先更新current，再调用renderRuntime。
4. 旧代码读取不存在的runtime.plan.required，抛出截图同款TypeError。
5. 因缓存渲染在try/finally之外，openingBatchId保持B，最新详情请求没有发出，DOM仍是RA。
6. 进入成片预览，实际捕获请求/api/batches/b/preview-url/RA。

这完整复现了线上日志所见“当前项目ID与其他项目素材ID拼接”，不再仅是代码推断。不能据此断言已取得用户浏览器当时的内存快照，也不能认定其加载的是旧前端版本。

## 修复

- 下载进度优先采用runtime.plan.required，兼容纳管项目的顶层plan.required；无计划或当前集不在列表时不显示错误的0/N计数。
- 将缓存渲染和切换初始化纳入既有try/catch/finally，失败隐藏工作区、清除缓存与切换标记，允许重新打开。
- 视频DOM记录所属项目，预览请求使用该绑定，并在发请求与接收响应时验证当前项目、选中项目及素材仍可预览。即使复制项目有同名素材ID，也拒绝旧DOM。
