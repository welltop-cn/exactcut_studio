## 1. 现状事实与核心约束

### 1.1 现有系统视觉与结构事实
- **页面布局基调**：浅灰底色（`--bg: #f3f6f6`）、纯白圆角卡片（`--paper: #fff`，`border-radius: 14px`）、深海青主色（`--brand: #087f77`，hover: `#066963`）、深青灰标题（`--ink: #152c39`）、蓝灰说明字（`--muted: #657a87`）。
- **素材预览卡片 DOM 规范**（`source/exactcut/web/app.js` 之 `renderAssets()`）：
  - `.asset` 容器：宽度 380px~440px 自适应网格（`.assets`），具有平滑悬停阴影。
  - 上半部 `.videoarea`：高度 380px~420px，背景 `#08151c`，内嵌 `<video controls playsinline>`，9:16 竖屏成片居中黑边展示。
  - 下半部 `.assetbody`：包含标题 `R91f0aaa0`、状态角标 `FBBM 已就绪`、文件名、预览/下载链接、时长与 Facebook 视频 ID、AI 重点展开行、耗时折叠栏、确认复选框与上传按钮。
- **视频内容特殊性**：短剧成片已普遍烧录英文对白硬字幕（位于视频画面下部约 75%~85% 处），下方紧邻 HTML5 原生播放器进度控制栏（高约 44px）。

### 1.2 用户核心诉求与约束
- **仅预览使用（用户明确确认）**：新增中文字幕只在浏览器预览播放器中显示，包含普通播放和全屏播放；采用独立 `TextTrack/VTTCue`，不烧录、不封装进任何视频文件。
  - 识别结果单独保存为预览辅助数据，不接入正式渲染、导出、下载或 FBBM 上传链路；开启开关不改变最终正片内容和文件哈希。
  - 下载与上传继续使用现有正式成片，均不附带本功能生成的中文字幕；原视频已有字幕保持原样。
  - 控制栏附近展示简短说明：**「中文字幕仅供预览，不影响下载或上传的成片。」**
  - 验收必须核对：生成、开启与关闭字幕前后，正式成片哈希不变，下载与上传仍指向原有正式成片。
- **核心约束（用户明确强调）**：**『主要要结合已有 UI，不要大改』**。
  - 不得重排整体页面架构、不得另造全局 Dashboard、不得修改全局侧边栏或改动深色主题。
  - 严格保持现有字号、圆角、青绿色强调、间距以及白底卡片节奏。
- **功能目标**：
  1. 每条素材预览卡片增加「生成中文字幕」开关；
  2. 首次开启异步调用后台 Gemini（不阻塞视频播放），显示进度/加载中状态；
  3. 识别完成自动弹出双语字幕完整时间轴弹窗，可关闭；
  4. 视频播放时同步展示中文字幕；
  5. 开关兼任显示开关：生成后关闭仅隐藏字幕，再次开启直接复用缓存，绝不重复调用 API 计费；
  6. 提供独立的「查看字幕时间轴」入口可随时重开；
  7. 弹窗内点击任意句子可跳转视频播放，并能让用户直观看到跳转效果；
  8. 切换项目或关闭开关期间完成不产生幽灵弹窗。

## 2. 选定方案架构（最契合系统的一套方案）

综合评估后，不堆叠多套方案，选择**最符合现有系统节奏与用户习惯的「单行紧凑工具条 + 浏览器原生中文字幕 + 原生 Dialog 弹窗」**一体化方案。

```
+-------------------------------------------------------------+
| [.videoarea 视频区] (高 400px，黑底 #08151c)                  |
|                                                             |
|   [ 浏览器原生中文字幕：你说什么？ ]     |
|                                                             |
|                    (竖屏短剧角色画面)                         |
|                                                             |
|              [ 原始烧录英文: What did you say? ] (下部约 80%)  |
|   [ 原生播放控制栏: 播放 / 进度条 / 00:33 / 全屏 ] (底部 44px)   |
+-------------------------------------------------------------+
| [新增 .subtitle-row] (紧凑行，高 40px，浅底 #f7fafa)          |
|   [开关] 中文字幕   ● 已就绪 (共 21 句 · 已缓存)  [📑 查看字幕时间轴] |
+-------------------------------------------------------------+
| [.assetbody 素材信息区]                                      |
|   R91f0aaa0                    [ FBBM 已就绪 ]              |
|   20261028_typezxraw_张一凡_agent_1_#101672#.mp4              |
|   轻量预览 · 上传使用正式成片 · 下载正式成片                   |
|   ...                                                       |
+-------------------------------------------------------------+
```

### 2.1 位置与布局设计
1. **控制条插入位置**：
   - 紧贴在 `.videoarea` 底部、`.assetbody` 内部信息之前。
   - 形成一个自然的“媒体控制延伸带”，逻辑归属于当前素材播放体验，不打乱下方正式业务字段（标题、FBBM 状态、确认复选框）。
2. **尺寸与视觉规范**：
   - 外层 `.subtitle-row`：高度 40px，内边距 `10px 14px`，背景 `#f7fafa`，上下边框 `1px solid #e7eff1`。
   - 开关组件：尺寸 `36px × 20px`，圆角滑块，激活态为品牌青绿 `#087f77`，未激活态为浅灰 `#cfd9dc`。
   - 状态文字区：字号 12px，自适应伸缩，字色随状态动态切换。
   - 查看时间轴按钮：次级按钮（`.secondary`），字号 12px，内边距 `5px 11px`，带 `📑` 图标。

## 3. UI 状态机与文案尺寸明细

| 状态 | 开关状态与文案 | 状态文字与图标 (`#subStatus`) | 时间轴按钮 (`#btnOpenTimeline`) | 画内字幕表现 | 触发行为与后台交互 |
|---|---|---|---|---|---|
| **1. 未生成 (Unloaded)** | 关；`生成中文字幕` | `未生成 · 点击开启识别` (字色 `#657a87`) | `disabled` 禁用态 | 隐藏 | 初始默认态。点击开关即进入 Loading。 |
| **2. 识别中 (Loading)** | 开；允许关闭，后台幂等防重复；`中文字幕` | `<span class="spinner"></span> Gemini 识别中 · 视频可照常播放…` (金黄字 `#91600c`) | `disabled` 禁用态 | 隐藏 | 触发异步任务。**视频绝不暂停或中断**。若用户中途关闭开关，标记 `suppressModal=true`。 |
| **3. 已就绪 (Ready/Showing)** | 开；正常；`中文字幕` | `<span class="dot-ready"></span> 已就绪 (共 21 句 · 已缓存)` (翠绿字 `#087750`) | 可点击启用；字号 12px | **同步渲染**：随播放实时显示当前对白 | 首次完成时自动弹出 `<dialog>`；后续开关操作即时生效。 |
| **4. 字幕已隐藏 (Hidden/Cached)** | 关；正常；`中文字幕` | `字幕已隐藏 (缓存保留，开启不重复扣费)` (字色 `#657a87`) | **依然可点击启用**，便于只查文本 | 隐藏；Native TextTrack 设为 disabled | 用户主动关闭。不销毁数据；再次开启**零延迟、零费用**恢复显示。 |

## 4. 关键交互细节与安全设计

### 4.1 字幕画内展示（用户确认：统一原生字幕）
- 普通播放与全屏播放均仅使用一个 `TextTrack/VTTCue`，删除自定义 HTML 字幕浮层，避免重复显示。
- 保留当前全屏展示方式：`cue.line = 2`。开关开启时 `mode = showing`，关闭时 `mode = disabled`。
- 时间轴高亮仍由播放时间同步。原生画中画与不同移动端浏览器的具体表现需分别实测，不能承诺全部一致。

### 4.2 双语时间轴弹窗交互（Native `<dialog id="timelineDialog">`）
- **弹窗样式**：
  - 遵循系统现有 `dialog` 规范：`border:0; border-radius:14px; max-width:620px; width:92vw; box-shadow:0 20px 80px rgba(0,0,0,0.35); backdrop: rgba(16,44,55,0.65)`。
  - 头部展示素材 ID `R91f0aaa0`、总句数（21条）、整片耗时与右上角关闭 `✕` 按钮。
- **点击句子跳转与视觉直观反馈**：
  - 列表内单条样式：展示起止时间码（如 `00:33.75 → 00:34.75`，monospace 绿底标签）、英文原句、中文加粗翻译。
  - **关键交互（解决遮挡痛点）**：
    - 弹窗顶部标配开关：`☑ 点击句子后自动关闭弹窗（便于观看视频）`（默认开启）。
    - 用户点击任一句子后：
      1. 执行 `video.currentTime = cue.start_ms / 1000`；
      2. 触发 `video.play()`；
      3. 弹窗立即平滑关闭，系统焦点平滑恢复至「📑 查看字幕时间轴」按钮；
      4. 右下角弹出 Toast 提示（如 `已跳转至 00:33 · "你说什么？"`）；
      5. 用户的视野立刻回到视频卡片，亲眼看到视频画面跳转并正在朗读该句，顶部字幕同步高亮！
    - 若用户需要逐句比对校对，可取消勾选该复选框，此时点击句子跳转视频，弹窗不关闭，且实时高亮当前正在播放的句子卡片（`border: 1px solid var(--brand); background: #eef8f5`）。
- **关闭弹窗与无障碍**：
  - 关闭弹窗**绝对不关闭字幕**（字幕依然在视频画面中播放）。
  - 支持 `Escape` 按键或点击蒙层关闭，关闭后恢复前序焦点。

### 4.3 状态隔离与边界防御
1. **识别不阻塞视频**：Gemini 识别期间，播放、暂停、全屏、拖拽进度条完全自由可用。
2. **关闭开关期间完成不强弹框**：用户在等待时若关掉开关或离开成片预览 Tab，后台完成时不强行弹出 Dialog，避免干扰用户当前操作。
3. **跨项目/跨素材状态隔离**：
   - 任务和回调以 `batch_id + request_id + sha256` 为复合键绑定。
   - 用户切换左侧项目或切换 Tab 时，旧素材完成事件绝不跨越弹出到新项目。
4. **单次付费与缓存固化**：
   - 识别结果按素材 Hash 缓存在前端 session 及项目持久化数据中。
   - 开关反复切换仅变更 `showing` / `hidden` 状态，不发起任何网络识别请求。

## 6. 后续主程落地实施建议（供协调者与主程 GPT 参考）

1. **接口复用建议**：
   - 可在现行素材详情数据中补充字段：`subtitles: { status: 'none' | 'processing' | 'ready', cues: [...] }`。
   - 首次触发请求 `POST /api/batches/{id}/assets/{request_id}/subtitles`。
   - 轮询或已有状态同步直接携带 `subtitles.status`，避免新开复杂的独立长轮询通道。
2. **样式挂载点建议**：
   - 无需大幅重构 `renderAssets()` 模板字符串，可在原有 `videoarea` 之后、`row`（标题行）之前，插入一行包含 `.subtitle-row` 的 HTML 片段。
   - CSS 集中增补于 `source/exactcut/web/index.html` 底部，类名全部以 `.subtitle-*` 命名空间隔离，零样式冲突。
3. **安全与回滚**：
   - 该功能为纯前端增量增强，开关默认关闭，完全不影响原有成片确认、质检检查与 FBBM 上传链路。

## 用户确认补充：自动排队

同一时间最多识别两条视频（集中配置可设为 1–2 条，默认 2），其余自动排队。每条视频内部逐段处理。开启后若需等待，控制栏显示「排队中」，轮到时自动切换为识别进度。排队期间可关闭字幕开关，但不取消已提交任务；离开项目后继续处理，完成不强弹框。重复开启同一任务不重复排队。已生成字幕立即显示，不占识别队列。
