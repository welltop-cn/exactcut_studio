# 剪切会话与结果状态设计

> 历史归档（2026-11-04）。正文保留当时的方案或执行状态，不代表当前版本；日常操作见[文档入口](../../README.md)。

2026-10-14。基于当前 cutting.js、cutting.py、cutting_scan.py 检查。本文是后续收敛规则，不代表全部已实现；优先于早期交互稿的冲突描述。

## 用户只面对两个页面

编辑页：当前项目视频、一个片段列表、选中片段的微调工具。AI 建议默认未勾选，用户勾选即进入删除方案，手动片段加入后默认勾选。分:秒:帧，从00:00:00开始，两端包含。

结果页：剪后视频、实际输出时长、已删除时长。只提供返回调整、下载、替换项目成片、放弃本次剪切。不出现原片时间轴、旧AI列表或待删除状态。生成成功不代表替换成功，也不代表AI已审查剪后视频。

## 各阶段及离开行为

| 阶段 | 显示与动作 | 关闭或刷新后重进 |
| --- | --- | --- |
| 准备视频 | 加载状态，禁用编辑 | 重取当前项目成片身份 |
| 编辑 | 原片和草稿；可手动编辑，AI不阻挡 | 恢复同一成片、同一会话的已保存草稿 |
| 生成中 | 固定本次方案、进度，不接受重复生成 | 后台继续；重进恢复任务状态 |
| 生成失败 | 原片和方案保留，明确原因及重试 | 显示失败任务，可重新生成 |
| 结果预览 | 剪后视频及结果操作 | 恢复匹配当前方案的结果 |
| 替换中 | 明确正在更新项目；禁止改方案、放弃及并发交付 | 查询后端操作状态，不根据断网推断失败 |
| 替换失败 | 后端证实未提交后，保留原片和可重试候选 | 恢复结果及错误；不必重新剪切 |
| 替换成功 | 刷新成片卡片和上传确认状态，退出编辑器 | 以新成片建立新的编辑会话 |
| 明确放弃 | 清空本次方案并使候选不可替换，当前成片不变 | 原片、空草稿，自动重新识别 |

普通关闭不等于放弃。未生成的草稿也应可放弃。对有修改/候选的显式放弃给一次简短确认：“放弃本次编辑？项目视频不会改变。”无修改时不弹确认。未加入的手动选区不得声称已保存。

返回调整保留方案。修改任何已选范围后，旧候选不再可替换；必须生成匹配新方案的结果。只查看片段或调播放位置不使结果失效。

## AI与草稿归属

AI报告绑定输入成片身份、识别配置和识别轮次；删除方案绑定同一来源及会话代次。不得将原片时间范围投射为剪后视频的AI结果。

普通返回同一草稿复用识别结果。明确重新识别发起新识别；运行中按钮禁用，不能瞬间返回旧报告并称识别完成。放弃后重进、替换后首次编辑均启动对应视频的新识别。

用户确认简化：重新识别先确认会重置AI建议及其勾选、微调，仅保留手动片段。请求被接受后重置旧AI项和撤销历史，新建议默认未勾选；提交失败保留原方案。任务执行失败可重试，不恢复旧AI项。零条报告写“本次抽样未发现疑似内容”，不宣称内容绝对安全。

AI异步返回只更新匹配来源、会话代次及当前识别轮次的状态；不切换页面、不更改结果摘要、不改变已提交生成方案。结果页无需为了隐藏的列表自动启动新的模型调用。

## 数据与并发

项目当前成片是唯一交付来源；生成候选不能成为当前成片。只有完整master/preview准备、校验及后端提交成功才切换引用。原始成片和旧预览后台保留，不展示历史版本，不覆盖或自动删除。

生成、放弃、替换必须校验来源及会话代次。旧窗口在另一个窗口放弃/替换之后提交时拒绝，并要求重新打开；不能复活已放弃草稿。相同生成和替换请求应可安全重试。网络超时表示结果未知，须查询实际任务状态再展示成功或失败。

已交付、排队、上传中或外部结果不明时禁止编辑/替换，前后端一致。上传使用当前成片及对应校验值，替换成功必须撤销旧预览确认。普通播放下载用当前引用；旧签名链接不能假装立即失效。

本地草稿不是跨设备可靠保存。若继续只用localStorage，界面只能承诺本机恢复，保存失败必须提示；不可无声宣称已保存。服务端会话代次负责否决旧本地草稿。

## 当前代码确认的缺口（待实施验证）

- 放弃按钮目前仅结果模式可见，编辑中的草稿没有同等明确的放弃入口。
- 用户已明确取消保留AI微调的需求，改为确认后重置AI项，保留手动片段。
- open先加载原片/识别再恢复结果，应先确定页面状态，避免结果预览时无谓启动识别或短暂露出旧编辑状态。
- 服务器验收复现旧窗口提交后已修正：生成、放弃、识别请求携带reset_at，在素材锁内与当前会话比较；旧窗口返回409，要求重新打开。
- 替换中关闭按钮有限制，但Escape和刷新同样需要状态恢复设计；请求异常不能统一称作替换失败。
- localStorage写入失败目前静默忽略，不满足明确保存状态要求。

## 验收场景

依次覆盖：新开空草稿；AI稍后返回时手动片段保留；零建议/识别失败；强制重识别确认/取消、重置AI微调并保留手动片段；草稿关闭恢复与放弃重进；生成中关闭恢复；生成失败重试；结果不显示原片列表；返回修改使旧结果失效；放弃后旧候选不可替换；替换失败原片不变；替换成功新片和新识别；替换请求超时但服务端成功；双窗口放弃/替换与旧请求冲突；交付开始后拒绝剪切；上传读取新成片。使用隔离项目验证，不操作用户待验收结果。
