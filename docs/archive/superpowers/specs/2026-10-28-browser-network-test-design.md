# 浏览器下载测速设计

> 历史归档（2026-11-04）。正文保留当时的方案或执行状态，不代表当前版本；日常操作见[文档入口](../../../README.md)。

状态：待确认；未实现、未部署、未修改 OSS。

## 目标

用户在素材工作台手动测量当前电脑到应用服务器、到实际阿里云 OSS 的下载表现，用于排查视频缓冲。测速由浏览器直接下载并统计实际读取字节与耗时，不以服务器下载替代用户链路。

## 方案与取舍

1. 推荐：应用服务器提供固定大小不可压缩样本；OSS 使用当前项目中用户有权访问、且已上传的成片或预览，签发短期下载地址，浏览器 Range 下载。无需上传新对象，结果贴近实际媒体链路；OSS 需要当前工作台的 CORS 权限。
2. 独立 OSS 专用测速对象：不依赖项目已有成片，但需要新增对象与维护流程；本轮不采用。
3. 服务器代理 OSS 下载：无法单独反映用户到 OSS 的链路，不采用。

第一项为实现建议，尚待用户确认。

## 页面

顶部“网络检测”入口，所有已登录用户可用。弹窗包含“开始检测”“停止”“复制结果”和两个独立结果行。当前项目有多个已上传素材时可选测试素材；无可用素材时仅测服务器，OSS 显示尚无可用测试素材。

结果包含测试时间、目标名称、实际字节、首个数据块等待时间、总耗时、平均 Mbps 和 MB/s。平均速度包含首包等待，标为本次下载实测，不代表宽带峰值。短样本明确提示样本不足，不作武断好坏评级。两条链路顺序测试，避免互相抢带宽。

显示进行中、成功、超时、用户停止、无样本和请求失败。浏览器 fetch 通常不能区分网络与 CORS 故障，不虚构确切原因。结果可复制，不包含签名 URL、Cookie 或密钥。提示暂停其他下载/视频可减少干扰，不自动暂停用户正在看的视频。

## 下载与服务端

- 每条链路最多读取 8 MiB，最多 20 秒；单次合计最多约 16 MiB（网络栈缓冲可能有少量额外传输），点击前告知。
- 服务器样本固定大小、随机内容、no-store，不压缩；浏览器加随机参数并禁用缓存。服务器端登录鉴权、每账号冷却、全局并发上限，异常断开释放槽位。
- OSS 只签发已保存且归属当前授权素材的有效上传回执；复用已有 OSS SDK 与集中配置。签名前校验对象命名空间、所属项目、大小及回执身份，不接受客户端任意 URL/对象 key，不触发上传、删除或桶 ACL 修改。
- 浏览器直接请求 OSS，使用 Range、omit credentials、no-referrer；拒绝无法核对的响应，读取达到上限即取消，不把错误页当成测速数据。跨域 Content-Length/Content-Range 可见时校验响应范围。
- 开始检测后禁重复启动；关闭弹窗/点击停止会取消请求；旧请求回调不能覆盖新结果。后台页切换提示结果可能受影响。
- 服务器测速测到的是浏览器到工作台入口的完整链路（包括代理），不是纯机房网卡速度。两次顺序测量不是相同时刻的对照实验。

## 已核对的 OSS 约束

2026-10-28 用现有生产 OSS SDK 只读 get_bucket_cors：当前规则允许 https://dailydrama.oulagrowth.com 与 https://dailydrama.oulaluu.workers.dev；GET/HEAD；请求头 range；暴露 Content-Length、Content-Range、Accept-Ranges、ETag。当前工作台 https://autocut.creativefitting.ai 未被允许。

建议在部署时追加一条仅允许 https://autocut.creativefitting.ai 的同等只读规则，完整保留既有规则；不使用通配来源、不启用写方法、不改 ACL。配置变更前保存原 CORS，修改后核对原规则仍在，并在真实工作台浏览器验证 Range 响应可读。失败恢复原 CORS。这是共享桶配置变更，需用户确认；本轮尚未执行。

## 验证与交付

测试先行：认证/授权、回执归属、速率限制、并发释放、下载大小、取消和超时、计算单位、分块计数、OSS 跨域失败、空项目、关闭重开及复制脱敏。使用隔离样本，不使用生产凭据进行开发测试。

本地完成后记录测试及浏览器验收；发布前完成仓库全量回归，通过现有 release manager 发布。不得把测速结果直接判定为用户网络故障，也不宣称测速功能修复了卡顿。
