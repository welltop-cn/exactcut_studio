# 马赛克工作台：单列表检查与可恢复勾选

2026-10-16。用户要求 agy 重新设计。已通过本机 agy CLI plan 模式检查现有前端和设计文档并产出原稿；本文件为结合用户要求及代码现实的审阅定稿。本轮仅完成设计，尚未实施取消采用的保留恢复机制。

## 用户任务

查看某个时间段的画面，调整需要遮挡的位置，决定是否采用。点击卡片表示“查看”，勾选表示“纳入本次打码计划”，两者独立；普通勾选不跳走。只有明确点击“采用并下一段”才推进。此阶段保存的是参考帧区域，尚未生成打码视频。

## 唯一布局

```text
视频马赛克                                           关闭
┌──────────────────────────────┬───────────────────────────┐
│                              │ 片段 7 · 已采用 5/8       │
│          视频画面            │ 识别进度 / 重新识别       │
│                              ├───────────────────────────┤
│                              │ 00:03–00:07    ☑ 已采用  │
│                              │ 简短画面原因              │
├──────────────────────────────┤                           │
│ 播放 / 逐帧 / 时间轴         │ 00:08–00:11    ☐ 已采用  │
├──────────────────────────────┤ 简短画面原因              │
│ 上一段 下一段 调整区域       │                           │
│             采用并下一段     │ 全高单列表，仅此处滚动    │
└──────────────────────────────┴───────────────────────────┘
参考帧区域，尚未生成打码视频 · 已保存到本浏览器
```

右侧固定头只占少量高度。只有列表容器允许纵向滚动，扫描详情不得增加第二个滚动区；长原因最多两行，点击当前卡片在左侧信息位置查看全文。取消已采用专用清单、折叠区与切换页。卡片无绿色大块，无重复时间和参考帧文案。右侧勾选框旁仅“已采用”，未勾选仍保留相同标签；如无框可用则禁用并解释原因。

左侧主操作栏位置固定。调整控件在预留位置按需显示，不盖住画面、时间轴、主按钮，不因展开而使操作栏跳动。第一版继续使用现有重画、像素输入与时间输入，不把八点缩放柄说成已实现。

## 状态及行为

| 状态 | 勾选框 | 点击卡片 | 勾选行为 |
|---|---|---|---|
| 已定位、未采用 | 未勾选且可用 | 查看参考帧与建议区域 | 保存该区域，位置不跳走 |
| 已采用 | 已勾选 | 查看当前保存的区域；可以调整 | 取消仅停用，保留坐标、时间、参考帧 |
| 取消后 | 未勾选且保持原位 | 仍显示用户最后调整的区域 | 直接恢复最后保存的数据 |
| 等待区域定位 | 暂不可用 | 可先检查时间段 | 等待有效区域或手动画框 |
| 未获得有效框 | 暂不可用 | 显示“请先框选区域” | 有效框准备好后可勾选；不自动采用 |
| 达到 8 个已采用区域 | 停用新增勾选 | 仍可查看/调整/取消 | 明示上限，取消一个后可恢复其他 |
| 识别中/部分失败 | 已有框仍可用 | 可查看已有结果 | 不因未完成而擦除已保存状态 |

一段一个区域：单个复选框固定在卡片右上角。多个区域：只有该片段选中时展开紧凑区域子行，分别勾选；未选中时给出紧凑数量或部分勾选状态，禁止一键无提示全选。区域名只在确需区分多区域时出现，不放在普通“已采用”之后。

手动画框不自动确认；先看到框，再勾选采用。取消采用不表示内容安全。没有模型结果不表示无风险。自动定位结果返回时不得覆盖用户改过的框。

## 草稿与兼容

保留区域对象与 adopted 布尔状态，而不是取消时 splice 删除。区域稳定标识不可仅依赖列表序号；模型重跑后的区间 ID 可能重用。区域记录关联素材 SHA、原时间范围和参考帧，人工调整不随列表刷新丢失。

现有 v1 已采用数组可导入为 adopted=true。新增完整工作台草稿保留停用区域；明确一个权威存储，兼容输出只能是投影，不能用两个互不协调的 key 当成双主。若需双写，必须处理部分写失败、旧页面并发写及恢复优先级。素材版本变化不可混用旧坐标。持久化失败不得提示保存成功或自动跳下一段。

## 对 agy 原稿的修正

- 删除“10 秒审完整片”的无依据承诺。
- 不用标识、纹身等举例扩展当前模型识别范围。
- 不自动勾选新画框，不在普通勾选后自动跳段。
- Enter 若以后加入，只在非输入框、非弹窗及区域有效且已保存时响应；本轮非必需。
- 不将已有结果隐藏到骨架屏，不使用无依据的百分比进度。
- SDK、SAM 等实现名不进入主操作文案。
- 旧 CSS 声明被后续样式覆盖，不把原稿中的所有样式诊断当作当前可复现事实。
