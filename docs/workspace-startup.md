# 首次进入与项目恢复

每个账号首次进入工作台时，系统创建一个“默认项目”，直接打开现有Hook与剪辑时间编辑器。项目为草稿，包含一条空白成片和一个空白剪辑片段。用户填写剧ID、日期、编导和制作内容，再确认开始下载与剪辑，预览确认后发布。

页面移除Excel导入入口、模板下载和原引导页。手动“＋新建项目”保留。项目未填剧名时显示“默认项目”或“未命名项目”，填写剧名后显示剧名。已有项目继续读取，历史导入解析和数据格式保持兼容。

首次创建与上次打开的项目按账号记录在`<数据目录>/.web-state/workspaces/<username>.json`；跟随data目录备份、迁移，不依赖浏览器localStorage。字段为`initialized`和`last_batch_id`。原有账号有自己的项目时，首次访问复用已有项目；管理员即使能查看其他人的项目，默认项目也属于管理员本人。

新增应用自身的接口`POST /api/workspace`（公网带配置前缀）要求登录与`X-Exactcut-Request: 1`，并经过现有维护门禁及跨进程mutation锁：

- 请求`{}`：初始化一次并返回上次项目；失效时优先返回自己的当前项目，再返回自己的归档项目。
- 请求`{"batch_id":"<32位项目ID>"}`：验证访问权限后记录选择。
- 响应`{"batch_id":"<项目ID>"}`或`{"batch_id":null}`。

并发请求串行检查持久化记录，复用同一默认项目。删除全部项目后，initialized记录仍保留，显示手动新建入口；刷新或重新登录不会自动补建。账号切换时以服务端记录恢复；有效的URL项目锚点可用于直接打开有权限的项目。

项目draft.json可包含可选`display_name`展示名，summaries透传；不改变持久化schema 1或数据库表。普通代码回滚保留最新业务数据和workspace记录，旧版本忽略新增字段。

回归覆盖首次创建、6个并发请求、账号隔离、管理员已有其他人项目、原有项目复用、服务端选项恢复、全部删除后保持空白，以及前端路径恢复。测试创建的账号与项目都在独立临时数据目录中。
