# 用户操作说明

适用对象：编导、素材制作人和审核人员。使用管理员提供的工作台地址，默认页面路径为 `/home/`；可用功能以该实例已发布版本及账号权限为准。

## 1. 新建项目与填写内容

使用个人账号登录。首次进入会创建默认项目，以后恢复上次打开的项目；需要独立制作批次时点击“＋ 新建项目”。普通账号查看自己的项目，同一部剧可以建立多个项目。

核对剧 ID、制作人、业务日期、素材类型及序号。一条素材对应一条成片，分别填写开头字幕、剧情片段和结尾。命名中的制作标识为小写 `agent`；遇到重名提示先核对已有素材。

当前网页直接填写内容。旧 Excel 导入说明属于兼容流程，不是新项目的操作入口。

## 2. 剧情片段与时间

按最终播放顺序添加片段。系统保留倒叙、回溯和重复区间，不会自动按集数排序。

先看页面标注的时间单位：

| 单位 | 填写含义 |
| --- | --- |
| 分:秒:帧 | 最后一组是原片帧号；按页面和原片索引校验，不按固定帧率自行换算 |
| 分:秒:毫秒 | 旧项目的最后一组表示毫秒 |
| 分:秒 | 如 `01:22` 表示 1 分 22 秒 |

“粘贴文本识别”一次只填写当前这条成片的需求。选择追加或替换，识别后核对集号、单位、起止点和顺序，再保存。AI 失败时可以澄清文字或手动填写；不要依赖含糊的时间简写。

旧文本时间线中的整集、到片尾写法不要直接填入新版数字框。原片缺失或时间超出范围时，按校验提示准备原片或修正输入。

## 3. 字幕、结尾与水印

- **开头字幕（Hook）**：填写文案，调整风格、重点词、位置和时长，保存并预览。文字不需要时可留空；显示不全时调整换行、字号或文案。
- **本段字幕**：只作用于对应剧情片段，与开头 Hook 分开设置。
- **中文字幕预览**：启用该功能的实例可按页面入口识别并查看预览，仍需人工核对文字和时间；生成预览不代表已经更新远端素材。
- **结尾画面**：选择不添加、剧情最后一帧或上传图片；检查停留时长、引导文字及静音效果。
- **剧名与 LOGO**：按需要开启，检查剧名是否正确、是否遮挡人物或字幕；静态结尾不加剧情水印。

## 4. 保存、制作与等待

点击“保存并校验”，核对各条素材的输入并修正错误，再点击确认制作。此操作开始准备原片、剪辑和技术检查，**不会自动上传 FBBM**。

执行进度展示排队、原片准备、制作和检查状态。任务在服务器后台继续，可以关闭标签页后再回来查看；关闭网页不等于暂停。资源不足时先等待已有任务释放，不要重复创建相同任务。

制作失败时先查看具体错误。修正输入后重新确认；仅有未完成条目时，使用页面对应重试入口。新版本制作失败，不代表之前可用的成片已被替换。

## 5. 审核与下载

逐条完整播放当前成片，检查：

- 剧集、片段顺序和首尾是否正确。
- 对白、声音、衔接和总时长是否符合要求。
- 字幕、重点词、水印及结尾是否完整、无遮挡。

技术质检不能替代内容审核。轻量预览用于快速查看，需要判断最终画质时下载正式成片。

若要把原片保存到自己电脑，使用剧 ID 旁的“下载原片”，核对集数并按浏览器提示保存。它与服务器准备制作原片是两个操作；正常制作不要求先下载到自己的电脑。

## 6. 剪切打码与替换

在已完成素材上打开“剪切打码”。可以识别疑似片段，也可以手工添加；AI 建议需要逐段检查。

1. 选择删除或打码，核对开始、结束时间及所选区域。
2. 字幕、角标可选固定位置，移动对象按需跟随；检查效果、强度和范围。
3. 生成处理后视频；排队期间可等待或使用取消入口。
4. 对照处理前后，检查画面、剪切衔接、声音和总时长。
5. 点击“替换项目成片”，再回到项目预览确认当前版本。

**只生成处理结果还没有替换项目成片。** 已经提交到远端的素材也不会因为本地替换而自动更新。

## 7. 确认上传与完成判断

有交付权限且实例开启交付时，完整预览当前版本，勾选确认后点击上传 FBBM。不要重复提交同一素材。

| 页面状态 | 说明 |
| --- | --- |
| 已提交、排队或文件上传 | 任务已经接收，仍在处理中 |
| 平台处理、继续查询 | 沿用原提交查询结果，不另建同名素材 |
| 已就绪 / 已入库，且有 Facebook 视频 ID | 才能判定交付完成 |
| 待管理员核实 | 先核实远端记录，避免重复提交 |

提交成功、文件传完或单独出现一个 ID，都不能代替完整交付结果。测试实例可能禁用交付，这是实例的用途限制。

## 8. 暂停、归档与反馈

暂停执行会保留进度；继续后可能等待调度。已发给外部平台的请求可能仍然完成。归档保留项目内容；复原后原本暂停的任务需要手动继续。处理期间是否允许归档，以页面实际提示为准。

永久删除只用于已归档项目，不设回收站；不会撤回远端素材，也不删除其他项目共用的原片。

反馈用于记录问题，不会自动修改视频。提供项目、素材序号、发生时间、具体时间点、操作步骤和错误文字；有诊断编号时一并提供，不要发送密码。
