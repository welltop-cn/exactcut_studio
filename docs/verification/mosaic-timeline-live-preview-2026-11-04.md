# 剪切打码时间轴与固定区域实时预览

## 范围

基于远端 main `9002646`，分支 `feat/mosaic-timeline-live-preview`。用户确认的范围为布局、缩略图时间轴、打码/删除时间块、固定区域实时预览和加载状态。

不增加时间轴缩放、快捷键、形状/旋转、关键帧或波形，不改变后端跟踪、编码、导出、上传策略。生成速度优化留待另行实测决定。

## 实现

- 现有片段列表放在左侧，预览居中，区域与效果放右侧；保留原控件和业务事件。操作按钮移到顶部。
- 列表内部滚动，左右面板不覆盖时间轴。紧凑卡片与参数控件；时间轴无标题说明栏，按实际轨道行数占用高度，重叠较多时内部滚动。
- 时间轴使用原片帧坐标；只显示已选择打码或删除的区间，未采用的建议保留在左侧。支持播放头定位、时间块两端修剪、整体移动。拖动完成通过既有草稿保存路径持久化，并保留跨页面草稿冲突保护和生成期间的编辑锁。
- 缩略图使用独立隐藏视频按整片均匀位置解码；最多 20 张，按当前内容宽度确定数量，不逐帧预取。关闭窗口时解除媒体源。缩略图失败不会阻止编辑。
- 浏览器 Canvas 合成固定矩形区域，最长边 960 像素；沿用已有样式、强度和范围扩大枚举。播放中仅在生效帧范围内显示，支持原画对比，调整参数无需请求后台 render。
- 左侧去掉效果入口，效果设置与动态预览集中在右侧。没有勾选打码时隐藏区域/效果控件，点选没有区域的“打码”仍可进入框选。保存时间不改变处理选择；保存打码区域后保持属性展开。移除“返回片段列表”导航。
- 跟随目标区域不被当作固定框效果展示；页面明确提示使用原有动态预览检查。后端跟踪流程、缓存与渲染流程保持原样。
- 准备期间显示 loading、隐藏操作按钮；成功展示编辑器，失败停止 loading 并展示错误。

## 验证

最新选择逻辑版本在 M2 通过 93 项编辑器/预览生命周期回归，在 Mac mini 通过这 93 项以及 22 项跟踪能力/队列 UI 检查，共 115 项。切换到右侧属性后，跟踪能力用例已改为先选中片段再操作右侧效果控件：

```sh
python -m pytest -q -m ui tests/test_mosaic_ui.py tests/test_mosaic_preview_lifecycle_ui.py
```

新增检查包括：

- loading 的等待/完成/失败；
- 打码与删除时间块分别拖动起点、终点、整体后，关闭重开保留时间，生成请求携带正确范围；
- 固定区域预览实际改变遮挡区域像素，区外不变，原画对比生效，没有后台 render 请求；
- 1512×717、1440×900 布局不重叠；8 个片段的真实滚轮操作可滚到底部，时间轴位置不变。

- 不勾选则无时间块/打码属性，打码→删除→取消选择正确切换，保存删除片段时间不意外采用打码区域。

之前的集成版本另通过 124 项跟踪能力、队列 UI、页面可见性、播放器、效果及生成测试。最新交互变更仍以明确列出的本轮检查为准。

独立真实视频检查使用 FFmpeg 生成 320×180、30fps、4 秒测试视频，经 Chromium 实际解码：15 张缩略图、2.1 秒时固定区域纯黑像素有效、3.1 秒离开打码区间恢复原画、播放持续、页面脚本错误为零。API 编排使用现有 UI 夹具；该检查不代表真实 SAM 跟踪或实际导出验收。

## 边界

- Canvas 与 FFmpeg 使用相同的效果枚举与尺寸比例，但浏览器滤镜和后端滤镜实现不同，模糊/柔边不宣称逐像素一致。界面提示生成后复核最终效果。
- 此次没有改导出编码，也没有宣称生成视频提速。
- 本机 18793 仅更新两个静态前端文件。运行后端的 `098ffad` 与 main `9002646` 产品源码一致，未重启、未更换数据或配置。后台健康版本号仍是旧标签，不能据标签判断前端是否更新。
- Mac mini 使用独立工作树做回归，未更新用户使用中的服务。
- main 和正式服务未变更。
