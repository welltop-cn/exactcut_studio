# 剪切打码时间轴与固定区域实时预览

> 当前交接：用户要求先只做固定位置的模糊/马赛克，并暂停本代理实现、交给 Grok bot。分支最新快照含未完成的 UI 简化和性能优化，存在 9 项 UI 回归失败，尚未部署 dev。请先读 [Grok 交接文档](../handoff/mosaic-fixed-simple-performance-grok-2026-11-04.md)。下文是此前分阶段验证记录，不能视作最新快照全部通过。

## 范围

基于远端 main `9002646`，分支 `feat/mosaic-timeline-live-preview`。用户确认的范围为布局、缩略图时间轴、打码/删除时间块、固定区域实时预览和加载状态。

不增加时间轴缩放、快捷键、形状/旋转、关键帧或波形，不改变后端跟踪、编码、导出、上传策略。生成速度优化留待另行实测决定。

## 实现

- 现有片段列表放在左侧，预览居中，区域与效果放右侧；保留原控件和业务事件。操作按钮移到顶部。
- 列表内部滚动，左右面板不覆盖时间轴。紧凑卡片与参数控件；时间轴无标题说明栏，按实际轨道行数占用高度，重叠较多时内部滚动。
- 时间轴使用原片帧坐标；只显示已选择打码或删除的区间，未采用的建议保留在左侧。支持播放头定位、时间块两端修剪、整体移动。拖动完成通过既有草稿保存路径持久化，并保留跨页面草稿冲突保护和生成期间的编辑锁。
- 缩略图使用独立隐藏视频解码，以约 56px 单格宽度计算数量（1512px 窗口为 27 张），居中裁切后连续铺满。先每隔 4 格取样，再填补其余位置；窗口变化后复用落在各格时间范围内的已有图片。当前页面保留同一素材至多 160 张缓存，换素材清空，关闭编辑器解除媒体源并取消待处理监听，重开可复用已解码图片。缩略图失败不阻止编辑。
- 浏览器 Canvas 合成固定矩形区域，最长边 960 像素；沿用已有样式、强度和范围扩大枚举。播放中仅在生效帧范围内显示，支持原画对比，调整参数无需请求后台 render。
- 删除区间直接覆盖缩略图条：半透明压暗与红色斜纹、“将删除”标记、选中边框、两端拖动及整体移动；取消后露出原缩略图。上方仅显示打码块，没有打码时不保留空轨道。此增量在 M2 的 94 项编辑器/预览回归通过，并以真实解码测试视频截图核对覆盖位置与透明效果。
- 左侧去掉效果入口，效果设置与动态预览集中在右侧。没有勾选打码时隐藏区域/效果控件，点选没有区域的“打码”仍可进入框选。保存时间不改变处理选择；保存打码区域后保持属性展开。移除“返回片段列表”导航。
- 原片播放即时跳过已选删除范围，先合并相邻/重叠范围；播放起点落在删除范围也会跳过，删除至片尾则停在最后保留帧，整片删除提示无可播放内容。暂停定位仍允许检查原始待删画面。此预览不触发后台 render；原画对比播放不跳删。
- 跟随目标区域不被当作固定框效果展示；页面明确提示使用原有动态预览检查。后端跟踪流程、缓存与渲染流程保持原样。
- 移除“更多工具”折叠栏，“识别当前帧”置于打码区域。片段卡片移除重复的“编辑”按钮，点击卡片即可展开时间；未采用打码时不展示区域属性。删除遮罩宽度不足时隐藏文字并保留完整 title，宽区间显示“删除”。逐帧按钮增加上一帧/下一帧提示。本轮 M2 的编辑器、预览生命周期、跟踪能力 105 项 UI 检查通过。
- 准备期间显示 loading、隐藏操作按钮；成功展示编辑器，失败停止 loading 并展示错误。

- 此次没有改导出编码，也没有宣称生成视频提速。
- 本机 18793 仅更新两个静态前端文件。运行后端的 `098ffad` 与 main `9002646` 产品源码一致，未重启、未更换数据或配置。后台健康版本号仍是旧标签，不能据标签判断前端是否更新。
- Mac mini 使用独立工作树做回归，未更新用户使用中的服务。
- main 和正式服务未变更。

## 固定位置简化接手验证（Grok bot，2026-11-04 晚，UTC+8）

### 旧草稿 / 旧结果策略（已实现）
- 打开旧草稿或从旧任务恢复参数时，目标统一改为 `motion: fixed`，效果收敛为马赛克/模糊 + 标准强度 + 不扩大范围，并在生成按钮下提示“旧草稿已按当前规则改为固定位置…请播放检查后再生成”。
- 已生成结果的“替换”仍按**生成时实际处理方案**比较：旧任务目标缺 motion 视为 tracked（与后端默认一致），旧效果选项按原值比较。因此旧跟随/旧效果结果不能被当作固定方案替换；结果页说明原因，用户放弃结果后可按固定方案重新生成。
- 未采用“两边都把缺 motion 当 fixed”：后端对缺 motion 的目标实际做了 SAM 跟踪，这样会把不同处理方案的结果静默替换。
