### 帧数修复后暴露的测试基准错误

- 原 Linux 对照最低 33.93 dB，低于 35 的帧全部属于直接复制区间；这些帧与原片逐帧哈希完全一致。
- 重编码区间与完整效果路径对照最低 39.24 dB。完整效果路径存在 RGB/YUV 转换及有损重编码，不能把它作为复制帧的无损真值。
- 测试改为按夹具已知 GOP/切点列出精确编码区间：编码帧仍要求 ≥35 dB，所有复制帧必须与原片逐帧哈希相同，并核对两类帧数之和。不是下调阈值或跳过差异帧。
- 新增故障注入：只损坏复制帧 0 / 编码片段最后一帧 89，其余像素保持无损。要求拒绝异常候选并回退；最终输出逐帧等于正常完整重编码结果，防止 trim 漏掉尾帧或放行坏结果。
