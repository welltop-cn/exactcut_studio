# 固定位置打码

手动添加片段默认固定位置，调整侧栏可选固定位置（字幕/角标）或跟随目标（人物/物体）。既有草稿和 AI 区域仍默认跟踪，不自动改动用户选择。保存区域后模式持久化，片段预览与整片输出使用相同模式。

API 扩展：render/clip-preview 的 target 可选 `motion: fixed | tracked`，缺省 tracked；服务端规范化 tracked 为旧字段集合，fixed 保留并参与任务标识。固定模式仍校验源帧范围、参考帧及像素边界，但不受 SAM 10 秒/300 帧限制，不要求 SAM 配置。旧单目标 track 接口拒绝 fixed，提示使用片段效果预览。

固定区域直接在每帧合成遮罩，按源尺寸缩放矩形，限定 start（含）到 end（不含）；不写逐帧 PNG、不启动跟踪。复用现有效果、扩展、预览缩放、音频保留和删除合成路径。字幕移动需用户分段设置不同位置。

验证包含：无 SAM 的真实 FFmpeg 完整生成与片段预览、原片校验值不变、固定遮罩起止边界、实际输出像素、超 10 秒固定范围、非法模式拒绝、手动默认模式/重开/生成、AI 默认跟踪/切换固定/预览请求。合成夹具截图 `/tmp/mosaic-fixed-position.png`。

验证结果：渲染/跟踪/效果 32 项通过，完整 UI 54 项通过；最终默认模式修正后手动/固定位置相关 UI 再次通过。`git diff --check` 通过。
