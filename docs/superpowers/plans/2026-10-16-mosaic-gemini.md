# Gemini 打码区域识别：第一阶段

> **For agentic workers:** Use subagent-driven-development for implementation and independent review.

**Goal:** 在独立马赛克工作台内识别指定原片帧的候选遮挡区域，让用户查看、调整并保存待跟踪目标。

**Architecture:** 马赛克与剪切使用独立入口、弹窗、JavaScript、API、会话和草稿。异步定位任务绑定原片摘要、重置版本、片段及参考帧；复用现有 Gemini 配置和凭据。候选框与已确认目标只代表参考帧，不参与删除渲染、替换或虚构动态预览。

**Tech Stack:** Python、google-genai、现有 HTTP handler、原生 JavaScript、Playwright。

## 工作顺序

- [x] agy 只读设计独立马赛克工作台的分阶段交互，保存完整方案。
- [x] 后端先补测试：坐标转换、空结果与失败区分、非法帧范围、鉴权、重置隔离、异步成功和失败。
- [x] 实现独立定位模块及 POST/GET 端点，任务有界、凭据不持久化、模型调用不阻塞修改锁。
- [x] 前端在准确帧就绪后发起识别；列表和叠加框展示候选，支持重新选择参考帧、人工修正、确认和移除。
- [x] 对已确认目标明确显示“待跟踪”，保存在来源与重置版本绑定的本地草稿；第一阶段不得混入渲染请求。
- [x] 验证播放或切换帧隐藏旧框、迟到响应不覆盖新选择、关闭重开恢复草稿、空结果与失败可重试。
- [x] 回归剪切、识别及替换相关测试；独立规格审查后做代码质量审查。

## 验收边界

首阶段不安装 SAM、不生成动态遮罩、不自动修改删除勾选、不上传或替换原片。真实 Gemini 验收只使用明确授权的开发凭据和开发素材；模拟接口测试必须明确标注。
