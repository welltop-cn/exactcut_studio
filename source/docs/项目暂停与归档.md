# 项目暂停与归档

项目在网页中按制作批次管理。同一剧可以有多个独立批次，共用原片。

- 暂停执行：停止该批次本机的执行进程及子进程，保留进度；排队任务暂停后不会启动。
- 继续执行：恢复现有进程；有其他任务运行时显示“等待继续”，轮到后恢复。
- 归档项目：移入左侧“已归档”；正在执行或排队的批次同时暂停。不会删除原片、成片、Excel、反馈或执行记录。
- 取消归档：移回“当前项目”。原先暂停的任务仍保持暂停，需要手动继续。
- 已归档项目可查看内容和预览，不能开始制作或上传；可复制为新草稿。

暂停针对本机进程，已经提交到 Gemini、OSS 或 FBBM 等外部服务的请求可能仍会完成。长时间暂停后外部连接可能超时，恢复后若显示失败，请使用重试操作。电脑重启导致原进程丢失时显示“任务已中断”，不能从内存断点恢复。

控制状态保存在 `.web-state/batches/<批次ID>/control.json`，与制作状态分开，避免工作进程覆盖暂停或归档意图。信号发送前验证 PID 和进程启动时间，避免误操作复用 PID。进程树暂停不影响网页服务与其他批次。

## 部署

新版服务由 `com.oulagrowth.exactcut.web-v2` LaunchAgent 启动，端口 8791；Cloudflare Tunnel 指向该端口。`deploy/install.py` 生成对应配置。

2026-09-24 在线迁移时保留了旧 8790 服务及其正在制作的子进程；旧 LaunchAgent 已禁止未来自动启动，新服务识别现有制作进程并协调暂停/继续。不要强制结束旧服务或其进程组，以免中断旧批次。确认旧批次完成后，可移除旧服务。

## 左侧快捷操作与永久删除

悬停左侧项目卡片（或用键盘聚焦）显示快捷按钮；触屏设备直接显示。当前项目显示“归档”，已归档项目显示“复原”和“删除”。

永久删除需要确认，只能删除已归档项目。执行进程先退出，再清除该批次目录、对应的导入副本、任务日志及反馈记录，不设回收站。共用原片、其他批次和已经上传至 FBBM 的远端素材不受影响。复原只适用于归档项目，无法恢复已删除项目。
