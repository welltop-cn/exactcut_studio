# 标准剪辑 Excel 填写说明

本说明采用用户于2026-09-24提出的分列填写方式，作为下一版模板规范。现有v2模板仍使用单格片段文本；本次仅落地说明，尚未将Excel与导入程序切换为分列格式。

## 表头

只填写剧ID、出表人。日期由系统按制作当天的北京时间生成，无需手动填写。

## 素材与片段

素材1、素材2等分别代表一条最终成片。一条素材可以有多个片段，按片段序号依次拼接。每个片段只对应一集中的一个连续区间。

建议每行填写一个片段，采用以下固定列：

| 素材编号 | 片段序号 | 集 | 头·分 | 头·秒 | 头·毫秒 | 尾·分 | 尾·秒 | 尾·毫秒 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | 1 | 1 | 0 | 5 | 0 | 1 | 49 | 0 |
| 1 | 2 | 2 | | | | | | |
| 2 | 1 | 5 | 1 | 22 | 0 | | | |
| 2 | 2 | 6 | | | | 0 | 30 | 500 |

上表示例：

- 素材1：EP1第5秒到1分49秒，随后拼接EP2全集。
- 素材2：EP5从1分22秒到片尾，随后拼接EP6从片头到30秒500毫秒。

“集”直接填正整数，例如1表示EP1，不需要输入EP、冒号或其他符号。

## 头尾留空规则

“头”代表开始时间，“尾”代表结束时间。判断留空时分别看该端的分、秒、毫秒三个单元格。

| 集 | 头时间 | 尾时间 | 选段含义 |
| --- | --- | --- | --- |
| 已填写 | 三格全空 | 三格全空 | 使用该集全集 |
| 已填写 | 三格全空 | 已填写 | 从片头开始，剪到填写的结束时间 |
| 已填写 | 已填写 | 三格全空 | 从填写的开始时间剪到该集片尾 |
| 已填写 | 已填写 | 已填写 | 使用指定起止区间 |
| 未填写 | 三格全空 | 三格全空 | 全行无其他内容时是未使用行，不生成片段 |
| 未填写 | 任意填写 | 任意填写 | 缺少集数，需补充；不继承上一行集数 |

已填写素材编号或片段序号的行也必须填写集数。全空行可以忽略，不能将“只填集数”的行忽略。

## 分、秒、毫秒的填写

- 三列均填数字，不输入单位、点号或冒号。
- 分：非负整数。
- 秒：0–59的整数。
- 毫秒：0–999的整数。1秒等于1000毫秒。
- 一个端点的三格中，只要有一格填写数字，就视为明确指定时间；该端其余空格按0处理。例如头·秒填5，其他两格空白，表示第5秒。
- 只有该端三格全部为空，才使用默认片头或片尾。
- 数字0不等于空白。例如尾·秒填0、其他两格留空，表示结束时间为0，不表示剪到片尾。

| 目标时刻 | 分 | 秒 | 毫秒 | 规范显示 |
| --- | --- | --- | --- | --- |
| 第5秒 | 0 | 5 | 0 | 00:05.000 |
| 半秒 | 0 | 0 | 500 | 00:00.500 |
| 1分22秒80毫秒 | 1 | 22 | 80 | 01:22.080 |
| 1分22秒8毫秒 | 1 | 22 | 8 | 01:22.008 |

截图中的`01:22:08`仅凭显示无法确定末尾08的单位；某些剪辑软件末组表示帧数。不能直接把该组抄入毫秒列。若软件显示的是帧，应按素材的帧率转换，或先切换为毫秒显示再填写。模板统一使用毫秒，不混用帧编号。

## 拼接约束

1. 同一素材的片段序号从1开始连续编号且不重复，按序号拼接。
2. 同一集要选两段，写两行，重复填写集数；不在同一格写加号或逗号。
3. 允许重复片段、跨集回溯和局部后接全集。按填写顺序执行，不自动按集数排序、去重或删重叠。
4. 整集及到片尾都使用该集正片的实际时长；正片未到位时标注“待读取片尾时长”。
5. 确定头尾后，尾必须大于头，且两者不得超出该集实际时长。错误应指出素材、片段与字段，不自动调换或截断。
6. 本表分列格式用于正片选段。字卡、叠字、配音或旧素材引用不能写入集数和时间格，需另设明确字段再支持。

## 兼容旧表

旧表可以按已讨论确认的规则解读，再转换成上述明确字段。例如旧表`0.5s`转换为头·分=0、头·秒=5、头·毫秒=0。新输入直接填写数字列，不再使用个性化简写。
