# 账户与制作内容隔离

网址：https://cut.oulagrowth.com

管理员沿用原 admin 账户和密码。首次访问未登录时进入网页登录表单；旧管理员登录也可继续使用。右上角“账户管理”可创建制作人账户、停用/启用账户及重置密码。制作人首次使用由管理员提供的初始密码登录。密码至少12位。重置密码和停用账户会立即使该账户现有会话失效；停用不删除项目，也不自动暂停已提交任务。

制作人只看到自己导入或复制的批次。导入多个剧的 Excel 时，每个拆分批次都归当前账户。编导姓名自动从账户资料填写并在保存时由后端固定，素材仍按 `日期_类型_姓名_agent_序号_#剧ID#.mp4` 命名。不同账户的制作文件按独立批次目录保存；共享 FBBM 中的成片名称仍做全局重复校验。

管理员可以查看和操作全部批次，侧栏显示账户归属。历史批次统一归 admin，不改变历史编导姓名、成片或制作状态。管理员复制项目时，新草稿归管理员；制作人不能复制其他账户的项目。

各账户隔离的内容：Excel、标准化内容、批次状态、成片播放地址、制作操作、下载日志、导出清单与反馈。后端对每条批次接口校验归属，知道其他项目 ID 不代表有权访问。旧版全局项目、任务及日志接口仅管理员可用。

原片仍使用同一剧的共享目录，与 auto-cut 共用。制作任务统一排队，FBBM 使用现有共享凭据；点击上传后仍按现有流程进行。账户变更不增加下载副本，不创建另一套 FBBM。

账户数据保存在 `.web-state/accounts.sqlite3`，密码使用随机盐和 PBKDF2-SHA256 保存，不保存明文密码。会话使用随机令牌，数据库仅保存令牌摘要，7天到期。浏览器使用 HttpOnly、SameSite=Strict Cookie，公网 Cookie 带 Secure。登录连续失败会暂时限制该账户登录。

批次归属保存在 `.web-state/batches/<id>/access.json`。缺失归属的历史批次只允许管理员访问。数据库 audit 表记录账户管理及批次操作的账户、动作、时间和批次 ID，任务记录中的 actor 标记提交人。

删除已归档项目仍清除该批次文件、导入副本、日志和反馈；保留共用原片、其他批次、已上传 FBBM 素材及最小操作审计记录。上线时无需制作人账号清单，管理员可随时创建。
